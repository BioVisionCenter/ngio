def compute_delay(self, attempt: int) -> float:
    """Return the delay in seconds before retry number `attempt` (1-based).

    The delay is capped at `max_delay_s`, before and after jitter
    (a uniform factor in [0.5, 1.5]) is applied.
    """
    delay = min(self.delay_s * self._scale(attempt), self.max_delay_s)
    if self.jitter:
        delay = min(delay * random.uniform(0.5, 1.5), self.max_delay_s)
    return delay

RetryConfig ¶

Bases: BaseModel

Retry policy for ngio IO operations.

With the default max_retries=0 no IO operation is ever retried. An error is retried only if any entry of retry_on is a substring of f"{type(error).__name__}: {error}" (so both exception class names and message fragments can be matched), or if retry_all_errors is enabled (mutually exclusive with retry_on). Ngio's own errors (NgioError subclasses) are never retried.

Example 
RetryConfig(
    max_retries=3,
    backoff=LinearBackoff(delay_s=0.5),
    retry_on=["RequestTimeTooSkewed"],
)

get_config ¶

get_config() -> NgioConfig

Return the global ngio configuration singleton.

The singleton is built on first call rather than at import of this module. In practice import ngio already triggers that first call (see ngio.utils._zarr_utils), so NGIO_CONFIG_PATH must be set before importing ngio.

Note

Use _reset_config() to force a reload, e.g. in tests.

def get_config() -> NgioConfig:
    """Return the global ngio configuration singleton.

    The singleton is built on first call rather than at import of this module.
    In practice `import ngio` already triggers that first call (see
    `ngio.utils._zarr_utils`), so `NGIO_CONFIG_PATH` must be set *before*
    importing ngio.

    Note:
        Use `_reset_config()` to force a reload, e.g. in tests.
    """
    global _config
    if _config is None:
        _config = NgioConfig.model_validate(_load_config_data())
    return _config
